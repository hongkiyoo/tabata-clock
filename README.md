# Tabata Clock

브라우저에서 바로 쓰는 타바타 인터벌 타이머. 설치 없이 링크만 열면 되고,
홈 화면에 추가하면 전체화면 앱처럼 동작한다.

**→ https://hongkiyoo.github.io/tabata-clock/**

## 기능

- 준비 / 운동 / 휴식 / 라운드 / 세트 / 세트 휴식 전 구간 설정
- 프리셋 5종 — 타바타 정석(20/10 ×8), 타바타 ×4, 40/20 서킷, EMOM 10, 30/30 입문
- 세션 구성 스트립 — 시작 전 오늘 운동 전체를 비율 막대로 미리 보여주고,
  실행 중에는 같은 자리에 현재 위치를 표시
- 3·2·1 카운트다운 비프 + 구간별 전환음 (운동 = 높은 2연음, 휴식 = 낮은 1음)
- 화면 꺼짐 방지 + 상태 배지, 완료 시 화면이 꺼졌는지 자체 보고
- 설정 자동 저장, 오프라인 동작(Service Worker)
- 키보드: `Space` 시작·일시정지, `→` 건너뛰기, `Esc` 종료

타이밍은 절대 시각 기준으로 누적해 긴 세션에서도 드리프트가 쌓이지 않는다.

## 화면 꺼짐 방지에 관하여

이 앱을 자체 호스팅하는 이유다.

Screen Wake Lock API는 기본 허용 범위가 `self`라서 **교차 출처 iframe에서는
차단**되고 `NotAllowedError`로 거부된다. 임베드된 환경(예: 아티팩트 뷰어)에서
돌리면 화면이 그대로 잠겨버린다. 재시도로는 뚫리지 않는다 — 권한 정책이기 때문.

폴백으로 무음 루프 비디오 재생(NoSleep.js 방식)을 넣어 두었지만 **iOS에서는
실측 결과 화면 잠김을 막지 못했다.** 그래서 iframe 밖, 자체 도메인의 최상위
페이지로 서빙하는 것이 유일한 해결책이다.

앱 안의 **진단** 버튼이 원인을 구분해서 알려준다:

```
✅ Wake Lock 정상      [ok · frame:no · policy:allow]
❌ iframe이 차단 중     [NotAllowedError · frame:yes · policy:block]
❌ 브라우저가 거부      [NotAllowedError · frame:no · policy:allow]
```

마지막 경우는 웹으로 할 수 있는 게 없다. iOS 설정 → 디스플레이 및 밝기 →
자동 잠금 → 안 함으로 쓰는 수밖에.

## 구조

| 파일 | 역할 |
|---|---|
| `tabata.html` | 소스. 단일 파일 (HTML + CSS + JS) |
| `build.py` | `tabata.html` → `docs/` 정적 사이트 빌드 |
| `make_icon.py` | 아이콘 생성. 링의 빨강:민트 = 240°:120° = 20초:10초 |
| `docs/` | 배포본. GitHub Pages가 이 폴더를 서빙 |

```bash
python3 build.py        # 소스 수정 후 재빌드
```

로컬 확인은 `python3 -m http.server 8787 --directory docs` — Wake Lock과
Service Worker는 보안 컨텍스트가 필요한데 `localhost`는 여기 해당한다.
